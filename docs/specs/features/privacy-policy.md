# プライバシーポリシー

## 概要

日本の個人情報保護法（個人情報保護法）を意識し、取得する情報・利用目的・第三者提供先・保有期間・削除方法を開示する静的ページ（`/privacy`）を設ける。GDPR等の海外規制への完全準拠は目指さない（[security.mdのプライバシー関連の決定](../../architecture/decisions/security.md)参照）。

サインアップ画面のフッターリンク（利用規約・プライバシーポリシー・ヘルプセンター）は過去の[grill-meセッション](../../design/auth.md)で「仕様外要素」として一度削除されているが、本ページ実装後は正式なリンクとして復活させる。

## 掲載する内容

| 項目                 | 内容                                                                                                                                                                                                                                                                                        |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 取得する情報         | 表示名・生年月日・性別・居住地域（[プロフィールセットアップ](./profile-setup.md)）、家族構成（氏名・続柄・生年月日・性別）、取引データ（金額・日付・カテゴリ・取引先名）、レシート画像（一時的にGemini APIへ送信、保存はしない）                                                            |
| 利用目的             | 家計の記録・分析・グラフ表示、AIによる支出分析・アドバイス生成（[ai.md](./ai.md)）                                                                                                                                                                                                          |
| 第三者提供・委託先   | Clerk（認証・セッション管理）、Turso（データベースホスティング）、Vercel（アプリケーションホスティング）、Google Gemini API（レシート読み取り・AIアドバイス生成。[ai.mdの送信データ最小化方針](./ai.md#3-本格的アドバイスdetailed_advice)を適用）                                           |
| 保有期間・削除方法   | 利用中は保持する。カテゴリ・家族構成メンバー等の個別削除は論理削除（`deletedAt`）。**退会時はアカウント削除操作（Clerkの`UserProfile`）をトリガーに全データを完全削除**する（[security.mdの退会時の完全削除](../../architecture/decisions/security.md#退会時の完全削除2026-08-23決定)参照） |
| 機微フィールドの保護 | 取引先名・家族の氏名・生年月日はアプリ層で暗号化して保存する（[security.mdの列暗号化](../../architecture/decisions/security.md#機微データの列暗号化アプリ層暗号化2026-08-23決定)参照）                                                                                                      |
| 問い合わせ窓口       | （実装時に確定。個人開発のため運営者名・連絡先メールアドレスを掲載する想定）                                                                                                                                                                                                                |

## 将来検討（今回はスコープ外）

- Cookieポリシー（Clerkが発行するセッションCookie以外、現時点でトラッキングCookieは使用していない）
